# HiDoc 🩺
### *Connecting Patients and Healthcare Professionals*

HiDoc es una solución Full-Stack diseñada para digitalizar la experiencia de reserva de citas médicas. A través de una interfaz intuitiva y un backend robusto, la plataforma elimina las barreras de comunicación entre doctores y pacientes, centralizando la gestión de salud en un solo lugar.

**🔗 [Explora la Aplicación en Vivo](https://sample-service-name-zo7b.onrender.com)**

---

## 🌟 Funcionalidades Clave

* **Sistema de Citas en Tiempo Real:** Gestión dinámica de disponibilidad para evitar solapamientos.
* **Seguridad y Privacidad:** Implementación de autenticación de usuario basada en **JWT** para el manejo seguro de sesiones.
* **Arquitectura RESTful:** Comunicación eficiente entre el frontend y el servidor mediante una API estructurada.
* **Perfiles de Especialistas:** Directorio médico detallado con información relevante para la toma de decisiones del paciente.
* **Dashboard Personalizado:** Panel de control para que el usuario visualice sus próximas consultas e historial.

## 💻 Stack Tecnológico

| Capa | Tecnologías |
| :--- | :--- |
| **Frontend** | React.js, Context API, HTML5 Canvas, Bootstrap |
| **Backend** | Python, Flask |
| **Base de Datos** | SQLAlchemy (PostgreSQL / SQLite) |
| **Autenticación** | JSON Web Tokens (JWT) |

## 🚀 Puntos Destacados del Desarrollo

* **Lógica de Negocio:** Desarrollo de algoritmos para el emparejamiento de síntomas y especialidades médicas.
* **Frontend Reactivo:** Uso de **React Context API** para mantener un estado global fluido, permitiendo una navegación sin recargas innecesarias.
* **Manejo de Datos:** Modelos de base de datos optimizados con SQLAlchemy, incluyendo validaciones de campos opcionales para mejorar la experiencia de usuario.
